# UNIQ Supply Inbox Sorter — Upload Package

This folder is ready to upload as a static website. The homepage is `index.html`.

## Fastest way to publish

1. Download and unzip `uniq-supply-inbox-sorter-upload.zip`.
2. Open [Netlify Drop](https://app.netlify.com/drop).
3. Drag the extracted `uniq-supply-inbox-sorter-upload` folder onto the page.
4. Netlify will provide a public link that you can share.

## Other options

- Upload the extracted folder to GitHub Pages.
- Upload the extracted folder to Cloudflare Pages, Vercel, or an existing company web host.
- Keep `index.html` at the top level of the hosted folder.

The app runs in the visitor’s browser. Uploaded emails and orders are processed locally and are not automatically sent anywhere. Excel/PDF support loads browser libraries from public CDNs, so visitors need an internet connection while using those features.
